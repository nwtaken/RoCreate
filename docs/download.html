Add it to Chrome

  1. Unzip RoCreate.zip and keep the RoCreate folder somewhere permanent, because Chrome loads the extension from it.
  2. Open chrome://extensions and turn on Developer mode in the top right.
  3. Click Load unpacked and pick the RoCreate folder.

Then add RoValra: Get RoValra on the Chrome Web Store

Updating later: download again and unzip over the same folder. RoCreate notices the new version and reloads itself within a minute.
